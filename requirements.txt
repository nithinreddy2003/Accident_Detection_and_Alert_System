# The "+cpu" local version exists ONLY on PyTorch's own index, so pinning it
# forces pip to the ~200 MB CPU wheel. Without it, PyPI serves the CUDA build
# for Linux (multi-GB of nvidia-* deps), which blows Streamlit Cloud's disk
# and build-time limits. Verified: cp312 and cp313 linux wheels both exist.
